# Довідник із сушіння

Режими, підготовка, ознаки готовності й рецепти для електросушарки (Gorenje FDK500DE, 35–75 °C, 5 лотків).

**Сайт:** https://sushka.yakubovych.pp.ua

## Що всередині

- 80+ продуктів: гриби, фрукти, ягоди, овочі, зелень і трави, м’ясо й риба, горіхи, снеки, заготовки
- 20+ рецептів: джерки, кабаноси з фаршу, в’ялена таранька, пастила, цукати, чипси, гранола
- Розкладка по лотках, сушіння кількох продуктів разом, безпека м’яса й риби, зберігання

## Як влаштовано

Один статичний файл `index.html` без збірки. Дані продуктів і рецептів — масиви `P` і `R` у кінці файлу.
Щоб додати продукт чи рецепт, допишіть об’єкт у відповідний масив за зразком сусідніх.

Хостинг — GitHub Pages з гілки `main`, свій домен задано у файлі `CNAME`.

## Застереження

Часи й температури орієнтовні. Рекомендації щодо м’яса й риби — загальні, не заміна санітарним нормам.
